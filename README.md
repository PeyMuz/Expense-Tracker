# 💰 Expense Tracker

A simple and beginner-friendly Expense Tracker built using HTML, CSS, and JavaScript.

This project allows users to add income and expenses, view their transactions, and keep track of their financial balance. Transactions are stored in the browser using Local Storage, so the data remains available after refreshing the page.

## 🚀 Features

- Add income transactions
- Add expense transactions
- Display transaction history
- Automatically calculate total income
- Automatically calculate total expenses
- Calculate the current balance
- Store transactions using Local Storage
- Reverse transaction order to show the newest transaction first
- Delete transactions
- Responsive layout
- Smooth transaction animations
- Hover effects for transactions and buttons

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
